# docs-watch 提案レポートの形式

`~/.claude/docs-watch/reports/YYYY-MM-DD.md` に以下の構成で書く。

```markdown
# docs-watch レポート YYYY-MM-DD

## 見回り結果
| ソース | 状態 | 備考 |
|---|---|---|
| fable5-prompting | 変更なし / 変更あり / 取得失敗 | |

## 取り込み提案（N件）

### 提案1: <一読で分かる日本語の見出し>
- **ガイドの記述**: <該当箇所の引用1〜2文（出典 URL・節名）>
- **現環境**: <食い違っている箇所 file:line と現状の1行説明>
- **提案**: <何をどう変えるか。結果ベースの日常語で>
- **理由**: <なぜ取り込む価値があるか。推測を含むなら「推測込み」ラベル>

## 非提案（記録のみ）
- 却下済みのため非提案: <decisions.jsonl の該当 item>（却下理由: <reason>）
- 採用済み・対応済み: <item>

## 次のアクション
閣下の承認をもって反映作業に入る。承認/却下の結果は decisions.jsonl に追記する。
```

書き方の規律:
- 提案の本文は平易な日本語（専門用語には言い換えを添える）。閣下が読んで採否を決められる粒度にする
- 提案ゼロなら「取り込み提案」節は「なし（変更は現環境に影響しない内容）」と1行書く
- レポートは長くしない。診断の根拠列挙より「何を変えるか・なぜか」を優先する
