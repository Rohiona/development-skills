# Clipboard Screenshot Reader

Macのクリップボードに保存されたスクリーンショットを読み取り、内容を把握する。

## When to use

ユーザーが以下のような発言をしたとき:
- 「スクショを撮りました」「スクリーンショットを撮った」
- 「画面のスクショを確認して」「スクリーンショットの確認をお願いします」
- 「クリップボードの画像を見て」
- 「画面を見てください」「確認してください」（スクリーンショットの文脈で）

## How it works

1. 同梱の `scripts/save_clipboard_image.sh` を実行してクリップボードの画像を一時ファイルに保存する
2. Read ツールでその画像ファイルを読み込む（Claude Code はマルチモーダルなので画像を直接認識できる）
3. 画像の内容をユーザーに説明する
4. 一時ファイルを削除する

## Steps

### Step 1: クリップボードの画像を保存

Bash ツールで以下を実行:

```bash
bash SKILL_DIR/scripts/save_clipboard_image.sh
```

`SKILL_DIR` はこの SKILL.md があるディレクトリの絶対パスに置き換える。

出力されたファイルパスを控える。エラーが出た場合はクリップボードに画像がない可能性があるので、ユーザーにスクリーンショットをクリップボードにコピーし直してもらう（`Cmd+Ctrl+Shift+3` または `Cmd+Ctrl+Shift+4`）。

### Step 2: 画像を読み込む

Read ツールで Step 1 で得たファイルパスを読み込む。Claude Code は画像ファイルを視覚的に認識できる。

### Step 3: 内容を説明する

画像の内容をユーザーに伝える。文脈に応じて:
- UI のレビューを求められていればデザインや操作性について言及する
- バグ報告の文脈であれば問題点を特定する
- 一般的な確認であれば画面に写っている内容を簡潔に説明する

### Step 4: 後片付け

一時ファイルを削除する:

```bash
rm <filepath>
```
